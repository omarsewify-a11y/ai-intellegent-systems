Week 2 Day 2 Data Analysis
The analysis shows that Course requests are the most frequent category, meaning students mainly need academic support. Technical and Internship requests also appear often, showing system access and career support needs.

A number of requests are still pending, which suggests that response time can be improved. Message length differs across categories, meaning some issues require more detailed explanations.

These insights can help improve automation, reduce workload, and enhance student support efficiency.
